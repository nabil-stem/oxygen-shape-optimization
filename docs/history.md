# Earlier exploratory experiments

The current paper concerns the nine-family, membrane-cap-8 benchmark and its
declared controls. Earlier experiments explored tabular RL, Expected Sarsa,
proposal screening, source scaling and training duration under other settings,
including a membrane cap of 4. Their selected winners and policy averages are
not directly interchangeable with the current benchmark.

The [v0.1.0 source snapshot](https://github.com/nabil-stem/oxygen-shape-optimization/tree/v0.1.0)
retains those methods' original notes, exploratory tables, configuration files
and execution records. The [release assets](https://github.com/nabil-stem/oxygen-shape-optimization/releases/tag/v0.1.0)
preserve the full primary study data, executed sources, correction history and
validation evidence. Earlier development runs outside that primary scope are
not all distributed as raw data; the data-availability statement identifies
the archived scope.

The default branch presents the current reusable software and paper. Personal
launch/recovery scripts, chat-oriented plans, duplicate source snapshots,
hardware inventories and run-bound example configs are excluded from this
view. This curation does not change numerical results, erase unfavorable
comparisons or rewrite the released tag and evidence.
