# Data availability and artifact scope

Author: Nabil ES-SAADI, independent researcher. Software: MIT. Original generated
data, figures and research text: CC BY 4.0. See LICENSE, LICENSE-DATA.md and
THIRD_PARTY.md. No human participants or patient data are included.

Versioned release location:
https://github.com/nabil-stem/oxygen-shape-optimization/releases/tag/v0.1.0

The release candidate includes the complete two production directories used
by the current manuscript, the local paper-review packet and current source
code. This includes rejected evaluated proposals, atomic per-solve fields,
model parameters, initial/final masks, configs, seeds, all validation caches,
costs and executed source snapshots. It records 285 returned endpoints and
50,721 committed production solver calls. It does not selectively remove
unfavorable comparisons. Historical exploratory studies outside the manuscript's
primary production scope are documented in the repository but are not all
included in these data archives.

Archives are split below the GitHub per-asset limit. Download all numbered
code, main, classical and review ZIPs together with release_manifest.json.
SHA256SUMS.txt and embedded per-file manifests identify their exact contents.
The standard-library verifier checks every archive and payload hash before
reporting success. Extract all parts into the same new parent directory.

Original files retain historical local paths as provenance; the portable
analysis resolves only explicitly declared study roots and still checks the
original input hashes. Original manifests are not rewritten to pretend that
the runs occurred under a later commit. Production ran before the initial
source commit and is identified by executed-source hashes.

A tagged GitHub release is the present distribution mechanism. **No archival
DOI has been assigned.** Before a journal requires a persistent repository,
deposit these same verified archives in an appropriate archive such as Zenodo
and update the data statement with the actual identifier. This is not a claim
that any journal has approved the data-management plan.
